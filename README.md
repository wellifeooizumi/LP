# WELLIFE 越谷院 LP

HTML・CSS・JavaScriptのみで動作する、ビルド不要のランディングページです。

## ローカル確認

既存のチェックアウトを使い、次のコマンドをリポジトリのルートで実行します。

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

`index.html` を配信する静的ホスティングに、`styles.css`、`script.js`、`assets/` と一緒に配置できます。予約システムやサーバーへの送信機能は含みません。

## 公開前の確認事項

- 正式な院名・ロゴ・コンセプト文：既存サイトはアクセス制限で取得できなかったため、現在のブランド表記・文章・配色は提案です。
- 開院日・営業時間・電話番号・予約URL・体験会開催日と実施内容
- 500円の税込・税別表記、参加条件、所要時間、キャンセル規定
- 掲載内容と実際のサービスの整合性

未確定の営業情報・予約受付は「準備中」と表示しています。予約のボタンは受付準備中のダイアログを開きます。予約先が確定したら、実際の予約へのリンクに置き換えてください。

添付PDFはページ構成の参考に使用しました。別ブランドのロゴ・キャラクター・店舗数・無料体験・テレビ実績などは転用していません。

`assets/hero.webp` はAI生成の施術イメージで、実際の院内・スタッフの写真ではありません。ページ上に「施術イメージ」と明記しています。実際の写真のご用意ができたら差し替えてください。
